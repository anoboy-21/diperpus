# DIPERPUS

**Digital Perpustakaan Indonesia**

---

## Tentang Proyek

DIPERPUS adalah platform perpustakaan digital modern yang dikembangkan untuk mendukung seluruh jenjang pendidikan di Indonesia, mulai dari TK, SD, SMP, SMA/SMK.

Implementasi pertama digunakan oleh:

**SMP PGRI 7 Bandung**

---

## Tujuan

- Digitalisasi perpustakaan sekolah.
- Mendukung QR Code setiap anggota dan setiap eksemplar buku.
- Mendukung peminjaman massal buku paket.
- Mendukung laporan akreditasi sekolah.
- Mendukung notifikasi keterlambatan melalui WhatsApp, SMS, dan Email.
- Mendukung perubahan kurikulum Indonesia.
- Multi sekolah.
- Multi jenjang pendidikan.
